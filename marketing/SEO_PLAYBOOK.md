# Local SEO + SGE Playbook (DMV)

## Primary goals
- Rank for “mobile detailing + city” and high-margin services (ceramic coating, paint correction, mold remediation).
- Convert: calls + online booking via Fieldd link.

## Google Business Profile
- Service area and categories must be accurate.
- Post weekly: before/after, promos, seasonal reminders.
- Review velocity: daily requests + response SLA.

## Location pages (high ROI in DMV)
Create pages for core cities/areas:
- Arlington, Alexandria, Fairfax, McLean, Reston, Chantilly, Centreville, Woodbridge, Bethesda, Rockville, Leesburg, Ashburn, Fredericksburg

Each page:
- Service summary
- Pricing “starting at” (only if verified)
- FAQ (generated from KB)
- Strong CTA + booking link

## SGE / AI Overviews readiness
- Publish authoritative FAQs that match customer intent.
- Use structured data (FAQPage) from `/website/seo/structured_data.json`.
